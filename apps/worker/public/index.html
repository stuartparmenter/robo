Robot Arm Playground

Robot Arm Playground tests how AI models handle real robotics jobs in a browser simulator. You can connect a model over MCP (Model Context Protocol) and have it drive the arm using camera views and readings from its wrist and gripper, much like it would at a real workbench.

The puzzles start with fitting a peg in a hole and build up to running a small factory station. As the jobs get harder, the model has to recover when things move, check parts for defects, and adapt when a new batch comes with different instructions.
